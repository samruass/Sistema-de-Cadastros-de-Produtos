# Sistema-de-Cadastros-de-Produtos

Sistema simples para cadastro e gerenciamento de produtos, desenvolvido em Python e SQLite.


# Funcionalidades

Cadastrar produtos

Listar produtos

Buscar produtos

Atualizar quantidade em estoque

Remover produtos

Verificar estoque baixo

Tecnologias utilizadas

Python

SQLite

# Sobre o projeto


Este projeto foi desenvolvido para praticar Python e aprender a trabalhar com banco de dados utilizando SQLite.
